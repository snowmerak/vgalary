나의 미디어 라이브러리

기억나는 장면을,
내 컴퓨터에서.

사진과 영상, 중첩 ZIP·RAR 속까지 자연어로 찾아보세요. 앱과 미디어는 내 컴퓨터에 두고 사용합니다.

설치 스크립트 받기 ↓

Windows · macOS · Linux / Git, Node.js 22.13+, npm, Go 1.27.3+ 필요

1. 다운로드하고 설치하기

다운로드한 install.mjs가 있는 디렉토리에서 실행하세요. 

node install.mjs

설치기는 GitHub의 소스를 받아 웹 UI와 Go 서버를 빌드합니다. 설치가 끝나면 실행 파일의 위치와 시작 명령을 안내합니다.

터미널에서 바로 다운로드하기

Windows PowerShell

Invoke-WebRequest https://vgalary.saturday.ne.kr/install.mjs -OutFile install.mjs
node install.mjs

macOS · Linux

curl -fLo install.mjs https://vgalary.saturday.ne.kr/install.mjs
node install.mjs

2. 로컬 서버 시작하기

안내된 명령으로 실행 파일을 시작한 뒤, 브라우저에서 http://127.0.0.1:8181을 여세요. 설정에서 임베딩 서버와 Qdrant를 연결하고 디렉토리를 등록하면 됩니다. 영상 색인에는 FFmpeg가 필요합니다.

업데이트와 설치 위치

node install.mjs --update
node install.mjs --directory "원하는 설치 경로"

실행 중인 앱은 먼저 종료해 주세요. --update는 기본 설치 위치를 갱신합니다. 별도 위치를 사용했다면 같은 --directory를 함께 지정하세요. 앱 데이터는 사용자 설정 디렉토리에 유지됩니다.

이 사이트는 설치 파일만 배포합니다. 앱의 외부 공개 여부와 접속 방식은 직접 선택할 수 있습니다.
