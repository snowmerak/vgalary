사진과 영상, 중첩 ZIP·RAR 속까지 자연어로 찾아보세요. 앱과 미디어는 내 컴퓨터에 두고 사용합니다.

PowerShell 설치기 ↓ sh 설치기 ↓

Windows · macOS · Linux / Git, Node.js 22.13+, npm, Go 1.27.3+ 필요

1. 다운로드하고 설치하기

Windows에서는 PowerShell 설치기를, macOS·Linux에서는 sh 설치기를 실행하세요.

Windows PowerShell

Invoke-WebRequest https://vgalary.saturday.ne.kr/install.ps1 -OutFile install.ps1
.\install.ps1

macOS · Linux

curl -fLo install.sh https://vgalary.saturday.ne.kr/install.sh
sh install.sh

설치기는 GitHub의 소스를 받아 웹 UI와 Go 서버를 빌드합니다. 설치가 끝나면 실행 파일의 위치와 시작 명령을 안내합니다.

2. 로컬 서버 시작하기

안내된 명령으로 실행 파일을 시작한 뒤, 브라우저에서 http://127.0.0.1:8181을 여세요. 설정에서 임베딩 서버와 Qdrant를 연결하고 디렉토리를 등록하면 됩니다. 영상 색인에는 FFmpeg가 필요합니다.

업데이트와 설치 위치

Windows PowerShell

.\install.ps1 -Update
.\install.ps1 -Directory "원하는 설치 경로"

macOS · Linux

sh install.sh --update
sh install.sh --directory "원하는 설치 경로"

실행 중인 앱은 먼저 종료해 주세요. 업데이트할 때는 처음 설치한 것과 같은 스크립트와 설치 경로를 사용하세요. 앱 데이터는 사용자 설정 디렉토리에 유지됩니다.

이 사이트는 설치 파일만 배포합니다. 앱의 외부 공개 여부와 접속 방식은 직접 선택할 수 있습니다.
